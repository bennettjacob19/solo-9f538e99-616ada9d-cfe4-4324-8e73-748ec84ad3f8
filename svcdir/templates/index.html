查询 API

GET /resolve?name=<服务名>  ·  GET /resolve（返回整个目录）
GET /resolve?name=<服务名>&token=<凭据>（同时返回该凭据对应租约的状态）
POST /api/temporary  ·  POST /api/temporary/<名>/renew  ·  DELETE /api/temporary/<名>

命名备份与恢复只覆盖固定项；恢复成功会同时作废全部临时租约，恢复失败则保持原状。
